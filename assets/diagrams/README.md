# Historical diagrams

The `setup-development` and `release-recovery` Mermaid, SVG and PNG files in this directory document the published 6.x workflow. They are retained as historical assets, not instructions for the current workflow.

Use the current green flowcharts in the [README](../../README.md) and the [standalone onboarding guide](../../Getting_Started_with_Agent-Team.html). In particular, safely stopped parked tasks can release compute while retaining ownership, and eligible development-worktree cleanup does not require deployment.
