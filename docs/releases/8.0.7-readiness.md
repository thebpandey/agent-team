# Agent-Team 8.0.7 release readiness

Version 8.0.7 makes the latest-repository root `SKILL.md` an active native v8 entrypoint. Linux amd64 and Windows amd64 remain the only published native downloads.

## Entry-point contract

- The repository root and native Codex and Claude entrypoints all declare version 8.0.7.
- The root routes `setup`, `status`, and `start` to the installed native `agent-teamctl` contract and retains current model, team, task, review, and authority guidance.
- Historical Node package v7.3.1 materials remain historical. Its manifest, archive metadata, and archive name stay at 7.3.1 and do not define the active root-skill version.

## Publication gates

1. Run `go test ./... -count=1` and `go vet ./...` on Linux, macOS, and Windows.
2. Package with `go run ./cmd/vnext-release package --version 8.0.7 --commit "${GITHUB_SHA}"`; verify Linux canonical assets and the Windows bundle, manifests, SBOMs, checksums, allowlist, and deterministic bytes.
3. On a Windows runner, copy the source-root `SKILL.md` to an isolated discoverable Codex root. Confirm native installation reports that exact conflict without a manifest. Move only the CI-owned root outside discovery, retry the extracted Windows bundle, and verify native version and installed entrypoint metadata are 8.0.7.
4. Publish only after packaged canaries, rollback, provider verification, and revision-bound readiness evidence pass for the exact main commit.

This does not claim execution on a disconnected user Windows host. Native install, update, rollback, and uninstall retain their existing manifest-owned and conflict-preserving behavior.
