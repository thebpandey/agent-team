Each published ZIP has its own `.zip.sha256` sidecar. All three downloaded CI artifacts passed sidecar validation, ZIP CRC, an exact eight-file allowlist, and an 8/8 byte comparison against the tag's Git blobs. The five-file skill source is shared; each bundle contains only its matching installer plus `README.md` and `CUTOVER.md`. The first Windows candidate at `d701cb8` had CRLF-converted contents; the Windows-only pre-checkout fix at `9e6c4b2` removed that defect, and all final Windows members match Git exactly.

The Linux bundle from the immediately preceding commit was installed into disposable Codex and Claude homes and all five installed files matched the package bytes. The final release changed only the Windows workflow, not the Linux installer or payload; the final Linux CI installer test also passed. Native Linux Codex developer → independent reviewer → integration was previously observed after LeanCTX removal. Native Claude status was observed, but Claude worker dispatch was not. Windows and macOS native Codex/Claude worker canaries and installation from their downloaded ZIPs were not observed; installer CI and archive integrity must not be described as those host canaries.

Project Kickoff `0.6.0` handoff qualification and publication are tracked separately. Agent-Team v9 works without Project Kickoff, LeanCTX, Serena, Graphify, or a controller.
