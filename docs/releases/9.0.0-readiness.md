The standalone candidate must continue to work without Project Kickoff. Missing
Project Kickoff bridge evidence limits only that optional interoperability
claim; it must not be substituted for Beads, installer, archive-download, or
native-host evidence.

The v8 managed uninstaller covers every host in its manifest and discovers
default host homes even when explicit homes are supplied. The disposable smoke
therefore did not invoke it: doing so could inspect the live installation.
The live uninstall was attempted once after explicit approval and snapshot
review, but v8.0.15 reserves about 118 MB of journal preimages for 36 current
and historical entries against a 64 MiB cap. It rejected the operation before
changing managed files. There is no supported v8 backup-prune operation;
repeating uninstall or deleting backup files would not resolve the preflight.
The exact-byte snapshot is retained. A reversible whole-root retirement is
being assessed as a separately approved fallback, with both-host rollback
required because the v9 installer is sequential. Until that route is approved
and independently reviewed, do not install v9 over the live v8 roots or claim
live acceptance. After a safe cutover, run native-host canaries for every
OS/host combination claimed as supported.
