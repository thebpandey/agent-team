Build and review with an AI team.

Agent-Team takes an approved plan and coordinates AI agents to build it, check the work, and fix problems. You set the direction and approve important decisions; the team handles the day-to-day coordination.

From a task list to checked work.

The coordinator picks ready tasks, gives each agent a clear job, and keeps separate changes from colliding. Another agent reviews the result. Problems go back for repair before the changes are combined.

Combining code does not automatically publish it. If an approval or check is missing, the affected work waits until it is resolved.

TASKS

A shared task list

Keep priorities, dependencies, and progress together so agents know what is ready and what still needs attention.

REVIEW

A second set of eyes

A coordinator assigns the work, developers make changes, and separate reviewers check them against the task requirements.

CONTEXT

Less repeated explanation

Reuse agents for follow-up tasks and give them focused instructions. This reduces repeated context and helps control token use.

Spend less time managing agents.

Use Agent-Team when a feature, bug fix, or larger project needs several pieces of work and an independent review. It keeps track of assignments, results, and the next step so you can focus on decisions.

Know where things stand

See what is in progress, what passed review, and what is blocked. Saved progress helps you continue without reconstructing the work from chat history.

Keep work focused

Each agent gets a specific task and the information it needs. Clear responsibilities reduce duplicated effort and conflicting changes.

Have an idea but no plan yet?

Project-Kickoff helps you define the project and prepare its tasks. Agent-Team then coordinates the building and review.

Keep the project context when you switch tools.

Agent-Team is designed to keep tasks, decisions, and progress in the project so you can work in Codex or Claude Code. A running agent still belongs to the tool that launched it; finish or stop that work before continuing elsewhere.

CODEX

$agent-team status

Use the skill in Codex to check progress and coordinate its agents.

CLAUDE CODE

/agent-team resume

Use the skill in Claude Code to continue from the saved project records. Claude launches and manages its own agents.

Get started in your coding tool.

Install Agent-Team for Codex, Claude Code, or both. The installer keeps track of the files it manages and requires no external hooks.

Windows amd64

After publication, download the Windows bundle and its SHA-256 sidecar, verify, extract once, then run:

.\agent-teamctl.exe install --host both --json
Linux amd64

After publication, download the v8.0.12 release set, run sha256sum -c SHA256SUMS, extract, then run:

./agent-teamctl install --host both --json
Open your project and use the skill
$agent-team setup · start · task add · status · resume
