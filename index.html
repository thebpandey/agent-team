Coordinate work in your active session.

Agent-Team is a skill for Codex and Claude sessions. It uses Beads for tasks and Git for changes, helping you choose bounded work, build it in separate worktrees, review it, and integrate accepted changes. After install, type `$agent-team status` then `$agent-team start` in Codex, or `/agent-team status` then `/agent-team start` in Claude.

Beads tasks to accepted changes.

Beads holds live task state and Git holds revisions. Agent-Team selects ready work, prepares separate worktrees, sends changes through independent review, and returns findings for repair before integration.

Setup asks for approval before initializing Beads when needed. Integration follows a clean review; it does not publish code.

BEADS

One task tracker

Beads holds task status, dependencies, and progress. Agent-Team does not add a second live task database.

REVIEW

Review before integration

A separate reviewer checks the actual changes. Findings go back to the developer for repair and review again.

GIT

Changes stay in Git

Each assignment uses a separate worktree. Integrate only accepted changes and preserve uncertain work.

Keep coordination in the project.

Use Agent-Team for bounded work that benefits from separate changes and review. It reads Beads and Git to help you see assignments, review results, and choose what to do next.

Pause and resume

$agent-team pause or /agent-team pause stops new assignments and asks observable workers to checkpoint. Later, $agent-team resume or /agent-team resume inspects Beads and Git and preserves dirty or uncertain work. Workers do not persist after the host session ends.

A local dashboard snapshot

After accepted integration and Beads closure, Agent-Team can refresh `.agent-team/dashboard/index.html`. It is a local static snapshot, not a service or task authority.

Planning is optional

Project Kickoff v0.6.0 is a separate planning skill for creating a plan or preparing tasks. You do not need it to use Agent-Team.

Use the skill in your active host.

Install the v9 skill.

Choose your operating system's ZIP and matching SHA-256 sidecar. Each archive has the same skill and only its matching installer. The `any` label means no CPU-specific executable is included.

Windows

Download Windows ZIP · SHA-256. Compare the digest, then extract and install:

Expand-Archive .\agent-team-skill-9.0.0-windows-any.zip .\agent-team-v9
Set-Location .\agent-team-v9
.\install.ps1 -TargetHost both

Use `-TargetHost codex` or `claude` to install one host.

Linux and macOS

Linux ZIP · SHA-256
macOS ZIP · SHA-256. Verify and extract the matching ZIP, then run `./install.sh both` (or `codex` or `claude`). Check with `sha256sum -c` on Linux or `shasum -a 256 -c` on macOS.
