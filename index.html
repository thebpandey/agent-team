Agent-Team

Agent-Team is a skill for Codex and Claude Code. One orchestrator owns the plan and splits it into small tasks. Developers build each task in a separate worktree. A reviewer checks the result. Only verified work reaches the integration branch.

Type $agent-team help in Codex or /agent-team help in Claude Code.
