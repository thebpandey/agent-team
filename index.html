A clean path from scope to release.

Agent-Team keeps each change small enough to review and each handoff durable enough to resume. The flow below is the operating model for the current source.

Release needs an authorized target and exact evidence. Continuous mode can refill safe work while an eligible deployment batch waits.

01

One tracker

Beads or the designated TASKS.md owns task state. Checkpoints and setup receipts point back to it.

02

Small writers

Each developer owns a bounded assignment and path set. Shared entrypoints and resources are handled serially.

03

Proof before merge

Reviewers inspect the exact revision. Findings return to the task; accepted work integrates in order.

Switch between Codex and Claude Code without resetting the project.

Open the same Git checkout in the other host or a new session. The tracker, task IDs, settings, active run, claims, checkpoints, pending operations, and evidence stay in place.

In Codex

Run $agent-team setup, then continue with $agent-team status, start, resume, or the next action.

In Claude Code

Run /agent-team setup in the same project, then use the same action names. takeover remains a compatibility alias.

Current source correction

Recorded session, host, and epoch values are audit history. They do not decide who may continue the project. The host still checks that it is in the same Git project, and an unknown live writer still keeps its path occupied.

The tagged v7.3.1 archive predates this session-switching correction. Use the current source on main for this behavior.
