# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers and technical leads coordinating bounded implementation work in Codex or Claude Code.

## Product Purpose

Agent-Team coordinates parallel development through one task authority, isolated writers, independent review, serial integration, and explicit release evidence.

## Positioning

Foreground orchestration with durable project records and revision-bound transitions, rather than implicit session memory or an autonomous background scheduler.

## Capabilities and Constraints

- Current native release: 8.0.9.
- Supports Codex and Claude Code while preserving one project authority.
- Retained teams may queue up to eight tasks within an unchanged run snapshot.
- Linux amd64 and Windows amd64 are published native platforms.
- Claims about launch, review, integration, and release require exact evidence.

## Brand Commitments

The Agent-Team name, creator attribution to thebpandey, exact installed-version authority, and calm evidence-first voice must remain visible.

## Evidence on Hand

Release metadata, readiness records, public packages, checksums, tests, and current product documentation in this repository.

## Product Principles

- One authority for each kind of state.
- Parallel work stays bounded and independently reviewed.
- Recovery is explicit and evidence survives sessions.
- Missing authority never becomes guessed authority.

## Accessibility & Inclusion

The public site must remain keyboard accessible, responsive, readable with reduced motion, and understandable without relying on decorative imagery.
